Sobre mim

Desenvolvedor &
Solucionador de Problemas

Sou um desenvolvedor movido pela crença de que grande software nasce na intersecção entre curiosidade e disciplina. Minha base abrange linguagens de backend — Java, Python e Go — cada uma escolhida com propósito: Java para robustez e arquitetura empresarial, Python para pipelines de dados e experimentos com IA, Go para desempenho e concorrência limpa.

Além do código, sou profundamente interessado na camada de infraestrutura — como sistemas se comunicam, escalam e falham graciosamente. Me importo com o quadro completo: do primeiro commit ao container rodando em produção.

Atualmente, estudo ativamente o desenvolvimento com IA — não apenas como usuário de ferramentas, mas como alguém que quer entender a mecânica: como modelos são construídos, ajustados e integrados em produtos reais. Acredito que a próxima geração de software será feita por devs que pensam em engenharia tradicional e machine learning.

Tenho também uma paixão que une técnica e criatividade: o desenvolvimento de jogos. Criar um jogo do zero — física, lógica, experiência do jogador — é um dos maiores desafios que a programação oferece, e é exatamente o tipo de problema que me faz querer ir mais fundo.

Não busco tarefas fáceis. Busco problemas difíceis, ambientes desconhecidos e desafios que forçam crescimento real.
